# Site Surprise d'Anniversaire 🎂

Un site web interactif et romantique créé spécialement pour célébrer un anniversaire spécial. Le site propose une expérience immersive avec des animations, des messages personnalisés et une surprise musicale.

## ✨ Fonctionnalités

- 🎭 Design moderne et élégant
- 💝 Messages personnalisés avec animations
- 🎵 Lecteur audio intégré pour un message spécial
- ⭐ Effets visuels et animations fluides
- 📱 Design responsive pour tous les appareils

## 🚀 Installation

1. Clonez le repository :
```bash
git clone [url-du-repository]
```

2. Installez les dépendances :
```bash
npm install
```

3. Configuration des fichiers médias :
   - Placez vos images dans le dossier `public/`
   - Placez votre fichier audio `paulin.mp3` dans le dossier `public/`

4. Lancez le serveur de développement :
```bash
npm run dev
```

## 🛠️ Structure du Projet

```
src/
  ├── components/     # Composants React
  ├── styles/        # Fichiers CSS
  └── App.jsx        # Composant principal
public/
  ├── images/        # Images du site
  └── paulin.mp3     # Fichier audio
```

## 📝 Personnalisation

1. Messages : Modifiez les textes dans `App.jsx`
2. Style : Ajustez les couleurs et animations dans les fichiers CSS
3. Médias : Remplacez les images et l'audio dans le dossier `public/`
